## Architecture & technical decisions
1. Canonical internal symbol "XAUUSD"; provider symbols only at boundaries.
2. TradingView = display ONLY (official free embed widget). No scraping; TV
   data never enters analysis/execution. Machine data = CSV replay dataset.
3. No fake TradingView auth (consumer accounts have no bot OAuth). Broker auth
   = OANDA personal access token via GOLD_OANDA_* env only; never stored in DB.
4. Live execution = direct OANDA v20 REST; practice host default. The engine's
   replay loop remains paper-bound; the live adapter is gated behind the mode
   manager and requires an operator-configured broker + live data feed.
5. Analysis confidence is a transparent heuristic (0-100 + explanation), NOT a
   calibrated probability. Missing data is reported, never fabricated.
6. Migrations are additive; no data is ever dropped.
